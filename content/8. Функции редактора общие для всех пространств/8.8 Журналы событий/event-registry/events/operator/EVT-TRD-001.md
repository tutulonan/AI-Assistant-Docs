# EVT-TRD-001 Сохранение настроек столбцов легенды по умолчанию

> [!warning] Статус: draft
> Состав полей и моменты регистрации необходимо согласовать с разработчиками Инструмента Тренды.

## Связанные требования

| Требование | Связь | Исходы |
| --- | --- | --- |
| [[7.5.3 Легенда#BR-753-000 Настройки графиков в легенде\|BR-753-000]] | Бизнес-цель | Все |
| [[7.5.3 Легенда#FEAT-753-000 Настройка столбцов легенды\|FEAT-753-000]] | Исходная функция | Все |

| Параметр | Значение |
| --- | --- |
| Источник | `armo / armo` |
| Журналы | Журнал Оператора |
| Базовая критичность | INFO |

## Поля

Заполняются общие поля события. В параметрах события передаётся перечень изменённых настроек без пользовательских и технологических данных.

## Параметры

| Параметр | Источник | Секретный |
| --- | --- | --- |
| `changed_settings` | Перечень сохранённых настроек столбцов | Нет |
| `failure_reason` | Нормализованный результат проверки или сохранения | Нет |

## Исходы и триггеры

| Исход | Момент регистрации | Шаблон сообщения |
| --- | --- | --- |
| success | После успешного сохранения настроек по умолчанию | Сохранены настройки столбцов легенды по умолчанию: `<changed_settings>`. |
| validation_error | При отклонении некорректного набора настроек | Настройки столбцов легенды по умолчанию не сохранены: `<failure_reason>`. |
| system_failure | При техническом сбое сохранения | Настройки столбцов легенды по умолчанию не сохранены: системный сбой. |

## Нормативное соответствие

Событие относится к операционному журналу и создаётся для трассировки действий пользователя. Прямое нормативное сопоставление для события не установлено.
