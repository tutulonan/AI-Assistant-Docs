## Введение

Легендой называется область под графиками, в которой выводится информация о тегах и настройки внешнего вида графиков.  Легенда чаще всего представляется в табличном виде.

Легенда позволяет сопоставить график в области построения с названием тега, а также узнать дополнительную информацию о теге, которая не отображается на графике, например описание [[Функциональный блок (ФБ)|ФБ]].

## Бизнес-требования

### BR-753-000 Настройки графиков в легенде

**Источник:** Иван Ваулин

**Ревизия:** 12.2025

Пользователь должен иметь возможность настроить внешний вид графиков с помощью легенды, чтобы избавиться от необходимости открывать отдельное окно настройки для изменения наиболее часто меняющихся свойств графика.

### BR-753-001 Информация о теге

**Источник:** [[АО Апатит (Фосагро)]]

**Ревизия:** 12.2025

В легенде должна содержаться информация о теге:
- полный путь,
- единицы измерения,
- минимум и максимум в наблюдаемом диапазоне,
- количество точек в наблюдаемом диапазоне,
- описание ФБ и параметра,
- текущее значение и статус,
- минимум и максимум шкалы.

Данная информация необходима для проведения анализа данных технологического процесса и мониторинга работы системы.

**Acceptance Criteria:**

- Пользователь может вывести на экран любой столбец легенды за 1-2 клика.
- Пользователь может настроить под себя порядок и размер столбцов легенды.
- Пользователь может изменить настройки легенды по умолчанию.

### BR-753-002 Группы графиков

**Источник:** Иван Ваулин, [[АО Апатит (Фосагро)]]

**Ревизия:** 12.2025

Пользователь должен иметь возможность разделить графики на разные группы, чтобы уменьшить количество визуального шума в одной области построения.

**Acceptance Criteria:**

- Пользователь может за 2-3 клика поместить график в отдельную область построения.
- Перемещение графиков между областями построения происходит без перерисовки и загрузки не более чем за 1 сек в 90% на эталонном наборе данных – 8 трендов за сутки, когда в системе записывается 2 точки в секунду для каждого из тегов (172 800 точек на 1 график за сутки).
- Все области построения имею общую ось Ox и работают синхронно.

## FEAT-753-000 Настройка столбцов легенды

Настройки столбцов легенды являются общими на все графики. Пользователь может:
1) менять настройки в течение сессии – в этом случае при следующем открытии окна "Тренды" оно откроется с настройками по умолчанию,
2) менять настройки для шаблона – этот шаблон всегда будет открываться с заданными настройками, если они были сохранены,
3) менять настройки по умолчанию – в этом случае окно "Тренды" для этого пользователя будет открываться с заданными им настройками по умолчанию.

см. [[Перечень настроек в трендах]]

	- видимость графика,

### SR-753-001-000

**Теги:** #priority/high  **Источник:** UX

**Ревизия:** 07.05.2026

Пользователь должен иметь возможность задать размер шрифта в легенде. Шрифт задаётся целым числом >= 10. По умолчанию размер шрифта должен быть равен 14.

При вводе некорректного значения, поле должно сбрасываться до последнего корректного значения и для пользователя должен быть выведен тоаст с пояснением.

### SR-753-001-001

**Теги:** #priority/high   **Источник:** Альфа платформа

**Ревизия:** 12.02.2026

Пользователь должен иметь возможность выбрать 1 из 2 вариантов изменения размера легенды:
- **фиксированный размер** – на экране всегда показывается заданное пользователем количество строк в легенде, даже если не все из них содержат теги; если заполненных строк больше, чем заданный размер легенды, то появляется вертикальный скролл;
- **адаптивный размер** – на экране показывается столько строк, сколько графиков добавлено в легенду; пользователь задаёт максимально допустимое количество строк, если графиков больше, чем максимально допустимое количество, то появляется вертикальный скролл.

Количество строк задаётся целым числом от 1 до 16 включительно. При вводе некорректного значения, поле должно сбрасываться до последнего корректного значения и для пользователя должен быть выведен тоаст с пояснением.

Количество строк является суммарным на все группы графиков.

По умолчанию должен быть выбран фиксированный размер с 8 строками.

[[5.7.1.1 Генерация параметров из описателя ФБ#FEAT-5711-009 Представление параметров единиц измерения]]). Если в units не указаны единицы измерения для данного параметра, то должен выводиться прочерк.

Пример параметра, для которого заданы units:

```yml
parameters:
	OUT: {spec: [output], type: real, value: 0.0, description: {strings: OUT}}

units:
	OUT_EU: {spec: set, value: '%', parameters: [OUT, OUT_HSC, OUT_LSC, HALIM, HHALIM, LALIM, LLALIM, ALM_DB], description: {
      strings: OUT_EU}}
```

### SR-753-002-011

**Теги:** #priority/crit  **Источник:** UX

**Ревизия:** 18.05.2026

Пользователь должен иметь возможность задать в легенде положение шкалы Oy относительно области построения – слева или справа. По умолчанию для первых 4 графиков в группе должна быть выбрана опция "слева", для последних 4 – "справа".

## FEAT-753-003 Разделение графиков на группы

**Макеты:** https://www.figma.com/design/SnRDgKbMnowZ8oSvMSzhmr/Master-2.0--DCS-?node-id=18705-357086&t=5UlrDa7H2Hh1QLKZ-4

### SR-753-003-000

**Теги:** #priority/high  **Источник:** [[#BR-753-002 Группы графиков]]

**Ревизия:** 03.12.2025

Пользователь должен иметь возможность создать до 16 групп графиков с помощью команды контекстного меню и drag'n'drop. Каждая группа графиков должна иметь свою область построения (см. [[7.5.4 Настройка области построения#FEAT-754-001 Разделение области построения на несколько групп]]).

По умолчанию в трендах должна быть 1 группа графиков.

### SR-753-003-001

**Теги:** #priority/high  **Источник:** [[#BR-753-002 Группы графиков]]

**Ревизия:** 03.12.2025

Пользователь должен иметь возможность перемещать графики между группами с помощью команды контекстного меню и drag'n'drop.

В одной группе может быть не больше 8 графиков. При попытке поместить график в группу, в которой уже есть 8 графиков, перемещаемый график должен оставаться на исходном месте и для пользователя должно быть выведено пояснение в виде тоаста (см. макеты).

Если пользователь убирает из группы последний график, то группа должна исчезнуть из легенды и соответствующая ей область построения должна быть скрыта.

### SR-753-003-002

**Теги:** #priority/high  **Источник:** UX

**Ревизия:** 03.12.2025

Пользователь должен иметь возможность скрыть все графики в группе одной командой, не удаляя их из легенды. При этом должна быть скрыта область построения для этой группы.
