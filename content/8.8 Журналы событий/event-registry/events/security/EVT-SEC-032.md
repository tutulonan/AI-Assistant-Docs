# EVT-SEC-032 Подтверждение изменения защищенного параметра

> [!warning] Статус: draft
> Маршрутизация в Журналы Инженера и Оператора требует проверки по актуальным требованиям функций изменения параметра.

## Связанные требования

| Требование | Связь | Исходы |
| --- | --- | --- |
| FEAT-941-001 | Исходная функция | success, access_denied, validation_error |
| BR-884-000 | Правила нормализации | Все |

## Источники и маршрутизация

| Источник | Журналы |
| --- | --- |
| `armi / armi` | Журнал ИБ и Журнал Инженера |
| `armo / armo` | Журнал ИБ и Журнал Оператора |

**Базовая критичность:** ERROR. Для `validation_error` — WARN.

## Поля

Помимо общих полей обязательны `location`, `field_name`, `old_value` и `new_value`.

## Исходы и триггеры

| Исход | Момент регистрации | Шаблон сообщения |
| --- | --- | --- |
| success | После успешной повторной аутентификации и сохранения либо передачи значения | Пользователь `<actor_login>` подтвердил изменение параметра `<field_name>` с `<old_value>` на `<new_value>`. |
| access_denied | При отсутствии права `SG-PRM-004` | Отклонено изменение защищенного параметра `<field_name>`: недостаточно прав. |
| validation_error | При отклонении повторной аутентификации | Отклонено изменение защищенного параметра `<field_name>`: неверный пароль подтверждения. |
| system_failure | При техническом сбое после успешной проверки полномочий | Изменение защищенного параметра `<field_name>` не выполнено: системный сбой. |
