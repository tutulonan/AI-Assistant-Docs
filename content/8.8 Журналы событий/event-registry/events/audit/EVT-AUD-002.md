# EVT-AUD-002 Изменение настроек журналирования

> [!warning] Статус: draft
> Требуется связать событие с конкретным системным требованием.

## Связанные требования

| Требование | Связь | Исходы |
| --- | --- | --- |
| BR-887-001 | Аудит действий с Журналами | Все |
| FEAT-884-002 | Системные события аудита | Все |
| FEAT-887-001 | Аудит действий с Журналами | Все |

## Источники и маршрутизация

| Параметр | Значение |
| --- | --- |
| Источник | `service / audit-service` |
| Журналы | Журнал ИБ |
| Базовая критичность | ERROR |

## Поля

Помимо общих полей должны заполняться `field_name`, `old_value` и `new_value`.

## Параметры

| Параметр | Назначение |
| --- | --- |
| `field_name` | Наименование изменённой настройки |
| `old_value` | Значение до изменения |
| `new_value` | Значение после изменения |

## Исходы и триггеры

| Исход | Момент регистрации | Шаблон сообщения |
| --- | --- | --- |
| success | После успешного сохранения настройки | Изменена настройка журналирования `<field_name>` с `<old_value>` на `<new_value>`. |
| access_denied | При отсутствии необходимого права | Отклонено изменение настройки журналирования `<field_name>`: недостаточно прав. |
| validation_error | При недопустимом значении настройки | Отклонено изменение настройки журналирования `<field_name>`: недопустимое значение. |
| system_failure | При техническом сбое сохранения | Изменение настройки журналирования `<field_name>` не выполнено: системный сбой. |
