# EVT-SEC-001 Авторизация пользователя

> [!warning] Статус: draft
> Для согласования необходимо восстановить ссылки на конкретные SR раздела аутентификации.

## Связанные требования

| Требование | Связь | Исходы |
| --- | --- | --- |
| FEAT-921-000 | Исходная функция | success, access_denied, validation_error |
| FEAT-922-012 | Поведение при повторном входе | access_denied |
| BR-884-001 | Нормативный состав событий | Все |

## Источники и маршрутизация

| Параметр | Значение |
| --- | --- |
| Источники | `armi / armi`, `armo / armo` |
| Журналы | Журнал ИБ |
| Базовая критичность | INFO |
| Повышение критичности | access_denied → ERROR; validation_error → WARN; system_failure → ERROR |

## Поля

**Обязательные:** `event_id`, `event_code`, `correlation_id`, `event_time`, `recorded_time`, `outcome`, `action_name`, `severity`, `user_login`, `workstation`, `source_app`, `scope`, `message`.

**Условное поле:** `actor_is_admin` фиксируется по наличию эффективного права `SEC-SET-002` на момент попытки входа.

## Параметры

| Параметр | Источник | Секретный |
| --- | --- | --- |
| `login_input` | Запрос аутентификации | Нет |
| `denial_reason` | Нормализованный результат серверной проверки | Нет |

## Исходы и триггеры

| Исход | Момент регистрации | Шаблон сообщения |
| --- | --- | --- |
| success | После успешной проверки учетных данных и допуска к созданию сеанса | Успешная авторизация пользователя `<login_input>`. |
| access_denied | При отклонении входа из-за состояния учетной записи или запрета повторного входа | Отклонена попытка входа пользователя `<login_input>`: `<denial_reason>`. |
| validation_error | При неверных учетных данных или нарушении интервала между попытками | Неудачная попытка входа пользователя `<login_input>`: неверные учетные данные. |
| system_failure | При техническом сбое после приема запроса | Авторизация пользователя `<login_input>` не выполнена: системный сбой. |
