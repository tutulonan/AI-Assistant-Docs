# EVT-SEC-005 Изменение стандартных параметров аутентификации

> [!warning] Статус: draft
> Перечень вариантов должен быть сверен с актуальными требованиями настроек безопасности.

## Связанные требования

| Требование | Связь | Исходы |
| --- | --- | --- |
| FEAT-922-000 | Исходная функция | success, access_denied, validation_error |
| BR-884-000 | Правила нормализации | Все |

## Источники и маршрутизация

| Параметр | Значение |
| --- | --- |
| Источник | `armi / armi` |
| Журналы | Журнал ИБ |
| Базовая критичность | ERROR |
| Критичность validation_error | WARN |

## Поля

Помимо общих полей обязательны `field_name`, `old_value` и `new_value`. При изменении нескольких параметров формируется отдельная запись для каждого измененного поля.

## Варианты параметров

| Идентификатор | `field_name` | Формат |
| --- | --- | --- |
| `max_auth_attempts` | Максимальное число попыток аутентификации | Целое число или «Отключено» |
| `login_attempt_interval` | Интервал между попытками входа | Число секунд или «Отключено» |
| `inactivity_timeout_armi` | Время бездействия (АРМИ) | Число минут или «Отключено» |
| `inactivity_timeout_armo` | Время бездействия (АРМО) | Число минут или «Отключено» |
| `password_complexity` | Сложность пароля | Отдельная запись для каждого измененного параметра |
| `password_history_depth` | Глубина истории паролей | Целое число или «Отключено» |
| `password_lifetime` | Максимальный срок действия пароля | Число дней или «Отключено» |
| `reauthentication_operations` | Повторный ввод пароля | Включено или Отключено; отдельная запись для операции |
| `repeated_login_behavior` | Поведение при попытке повторного входа | Блокировка нового входа или перехват сессии |

## Исходы и триггеры

| Исход | Момент регистрации | Шаблон сообщения |
| --- | --- | --- |
| success | После успешного сохранения нового значения | Пользователь `<actor_login>` изменил параметр `<field_name>` с `<old_value>` на `<new_value>`. |
| access_denied | При отсутствии эффективного права `SEC-SET-002` | Отклонено изменение параметра `<field_name>`: недостаточно прав. |
| validation_error | При отклонении значения правилами валидации | Ошибка сохранения параметра `<field_name>`. |
| system_failure | При техническом сбое после приема команды | Изменение параметра `<field_name>` не выполнено: системный сбой. |
